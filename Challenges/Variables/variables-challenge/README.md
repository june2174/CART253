## Description
*Annoying bird and mrFurious* shows a bird moving randomly in vertical way and at the same time moving left to right. Plus it shows angry man gradually turning red as bird passes by. As background turns to drak blue, it shows the time has passed.
Mainly used random() function and variables to move and shake bird + mrFurious. To slow down the speed of the sky and mrFurious's color changing, I used *0.99... than adding numbers.
